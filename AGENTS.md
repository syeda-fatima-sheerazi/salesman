# SalesMan (package: `practices`)

Flutter sales management app — GetX state management, local SQLite auth.

## Quick start

```bash
flutter pub get
flutter run              # default device
flutter run -d chrome    # web
flutter analyze          # lint (flutter_lints defaults)
flutter test             # stale — see Known issues
dart run flutter_launcher_icons   # app icon
```

## Architecture

- **State / routing / DI**: GetX (`GetMaterialApp`, `GetView`, `Get.toNamed`).
- **Screen pattern**: `lib/core/screens/{name}/` → `{name}_view.dart`, `{name}_controller.dart`, `{name}_binding.dart`.
- **Routes**: `lib/core/routes/route_names.dart` (`Routes`) + `app_pages.dart` (`AppPages.routes`). Initial: splash (`/`).
- **Theme**: `AppTheme` (primary teal `#3D6F80`) in `lib/core/themes/`. Light + dark.
- **Responsive**: `flutter_screenutil` — design size `375 × 812`.
- **Assets**: `assets/animations/`, `assets/images/`, `assets/icons/`.
- **Services**:
  - `DatabaseService` (singleton) — SQLite via `sqflite`, SHA-256 password hashing via `crypto`. `users` table with unique email. Provides `registerUser()`, `loginUser()`, `getUserByEmail()`.
  - `SessionService` (singleton) — persists `logged_in_email` in `SharedPreferences` for auto-login.
  - `ShopService`, `LocationService` — return dummy data (no backend).
  - `AppSnackbarService` — wrapper around `Get.snackbar`.
- **Auth**: Local SQLite + SHA-256. Splash checks session → auto-navigates to dashboard or signup. Google Sign-In wired (needs OAuth client ID config for release).
- **DB init**: `main()` calls `await DatabaseService.instance.database` before `runApp`.

## Conventions

- **Imports**: use `package:practices/...` (not relative).
- **Route arguments**: passed via `Get.arguments` and type-checked (e.g. `UserModel` for dashboard).
- **Validation**: `AppValidators` in `lib/core/utils/`.
- **Currency**: `formatMoney()` outputs `Rs100,00` (comma decimal).
- **Screen triples**: every screen gets a view, controller, and binding file.
- **UserModel**: has `password` field. `fromJson`/`toJson` omit password; `fromMap`/`toMap` include it for SQLite. Do not expose password in JSON serialization.
